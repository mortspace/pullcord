PixelLoader

Loading states,drawn in pixels.

Loaders that say what is happening, each a hand-drawn 13×13 pixel sprite: a heart that beats, a hammer that strikes, a page that turns. Every loop is continuous, every state comes in several takes, eighteen spinners and twelve glow spinners cover the waits that need no story, and every state comes again as a 5×5 micro glyph for tabs and menu bars.

Sizing

One number rules a button: the glyph size G. Cell pitch is G ÷ 13, the label is 0.52 G, the button is 1.6 G tall with a 0.5 G radius and a fixed width of 8.5 G, so every button in a tier is the same box and the label sits in the same place. The art is always 13×13.

Legibility

These have to read for someone who has never played a game. Six rules keep them that way.

Familiar symbolEach state uses the symbol people already know from their phone: a magnifier, a speech bubble with dots, the Wi-Fi fan, an arrow into a tray.
Shape firstThe icon reads when it is frozen. Motion adds meaning, it never carries it alone. Things that travel, like the arrow streams, the circling magnifier and the crawling ant, are whole in the frozen pose, and no loop leaves the frame empty.
One gesture, easedOne idea moves at a time: a dot, a cursor, or a wave across a row that reads as one gesture. Motion starts slow, moves quickly through the middle and settles, sometimes a cell past its mark and back. Pixels cannot move by fractions, so the easing lives in how long each step holds.
Never stopsEvery loader is one continuous loop. No pose holds longer than about half a second, a blank frame is gone in a blink, and while a pose rests a shine sweeps across it, so a pause reads as a breath and never as the animation stopping and starting again.
White is an accentWhite marks the moving part, a few cells at most in any frame. A whole shape never flashes white.
Quiet gridThe unlit cells sit at 10% and the glow at 0.4, so the outline is sharp and the grid stays texture.

Usage

One component, one prop that names the state, and an optional variant that picks one of its takes, listed on each loader's page. Color follows the state unless you pass a tint. done and error stop on their final frame.

import { PixelLoader } from 'pixel-loader'
import 'pixel-loader/pixel-loader.css'

<PixelLoader state="heartbeat" size={32} label="Reading your heartbeat" />
<PixelLoader state="done" variant="bend" size={32} label="Done" />
<PixelLoader state="building" palette="ios" tint="systemBlue" />
<PixelLoader spinner="blocks" size={24} />
