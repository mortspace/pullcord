Sizing

One number rules a button: the glyph size G. Cell pitch is G ÷ 9, the label is 0.52 G, the button is 1.6 G tall with a 0.5 G radius and a fixed width of 8.5 G, so every button in a tier is the same box and the label sits in the same place. The art is always 9×9.

Usage

One component, one prop that names the state. Color follows the state unless you pass a tint. done and error stop on their final frame.

import { PixelLoader } from 'pixel-loader'
import 'pixel-loader/pixel-loader.css'

<PixelLoader state="heartbeat" size={32} label="Reading your heartbeat" />
<PixelLoader state="done" size={32} label="Done" />
<PixelLoader state="building" palette="ios" tint="systemBlue" />
